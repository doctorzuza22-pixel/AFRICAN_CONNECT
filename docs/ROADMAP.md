# African Connect product roadmap

## Release 0 — Cross-platform foundation
- Expo / React Native / TypeScript shared app
- Premium black and gold brand system
- Mobile navigation and country preference
- Demo social, business directory and marketplace flows
- Android debug APK pipeline

## Release 1 — Real accounts and trust
- Backend architecture and secure authentication
- Account recovery and device/session management
- Privacy controls, reporting and moderation
- Country and language preferences
- Identity verification through authorised providers only

## Release 2 — Community and commerce
- Real user profiles, posts and messaging
- Merchant onboarding and seller verification
- Product catalogue, inventory, orders and returns
- Partner checkout and payment integrations

## Release 3 — African services network
- Official retailer and service-provider integrations
- Music, health, travel, jobs and education discovery
- Cars and property listings with appropriate verification partners
- Additional African countries and currencies

## Release 4 — Platform scale
- iOS distribution
- Performance, accessibility and localisation
- Security testing, operational monitoring and support
- Partner APIs and developer ecosystem

All milestones are subject to testing, provider agreements and applicable country laws. The current app is an early demo, not a production service.
